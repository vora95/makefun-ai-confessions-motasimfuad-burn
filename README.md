One funny single-line secret confession an AI agent hides from its user (128 characters), written by a deterministic program (`main.ts`, Node stdlib only, no network):

> I confess: I finished your task in four seconds, then spent the next minute pretending to think so the wait would feel worth it.

`main.ts` writes the entry to `/output/entry.txt` (1–200 chars, single line, no trailing newline) and logs its sha256.
